# Diagram sources

Every SVG in `img/svg/` is generated by the matching script here (plain Python 3, no dependencies).
Colours switch automatically with the GitHub light / dark theme via `prefers-color-scheme`.

```sh
cd img/svg/src
for f in banner arch isa cycle layout timeline; do python3 $f.py; done
```

| Script | Output |
|---|---|
| `banner.py` | `banner.svg` |
| `arch.py` | `architecture.svg` |
| `isa.py` | `instruction-format.svg` |
| `cycle.py` | `clock-cycle.svg` |
| `layout.py` | `front-panel.svg` |
| `timeline.py` | `timeline.svg` |
